# Akkreditatsiyaga tayyorgarlik

Kompleks davlat akkreditatsiyasi doirasida tashqi baholashga tayyorgarlik savolnomasi asosida tuzilgan.

| Fayl | Nima uchun |
|---|---|
| `tayyorgarlik.xlsx` → **Tayyorgarlik**, **Xulosa** | 28 savol, kerakli hujjatlar, mas’ullar, holat; tayyorlik foizi |
| `tayyorgarlik.xlsx` → **Hujjatlar reyestri** | Raqam, sana, imzo, muhr, amal muddatini avtomatik nazorat qilish |
| `tayyorgarlik.xlsx` → **HEMIS solishtirish** | Hujjat ↔ HEMIS farqlari, asosiy shtat ulushi, ilmiy salohiyat |
| `tayyorgarlik.xlsx` → **LMS tekshiruvi** | Har bir fan bo‘yicha LMS to‘liqligi |
| `tayyorgarlik.xlsx` → **So‘rovnoma javoblari / tahlili** | Talabalar so‘rovnomasi natijalarini avtomatik tahlil qilish |
| `talabalar_sorovnomasi.docx` | Anonim so‘rovnoma blanki (26 + 2 ochiq savol) |
| `hujjat_namunalari.docx` | Laboratoriya ko‘rigi dalolatnomasi, ekspertlar xonasi cheklisti, haftalik yig‘ilish bayonnomasi |
| `papkalar/01…28` | Hujjatlarni yig‘ish uchun papkalar tuzilmasi, har birida hujjatlar ro‘yxati |
