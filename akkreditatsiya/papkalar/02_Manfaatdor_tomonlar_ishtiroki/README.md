# 2. Ta’lim dasturini qayta ko‘rib chiqishda ish beruvchilar, talabalar va bitiruvchilar ishtiroki hujjatlar bilan tasdiqlanganmi?

**Bo‘lim:** II. Kafedra va ta’lim dasturlari  
**Mas’ullar:** Mamajonov I., Turg‘unboyev Sh., Maxkamov I., Xamraqulov J., Isroilova D.

## Shu papkaga joylanadigan hujjatlar

- [ ] Ish beruvchilar bilan uchrashuv bayonnomalari, takliflar (xatlar)
- [ ] Talaba/bitiruvchi so‘rovnomalari va tahlili
- [ ] Takliflar asosida dasturga kiritilgan o‘zgarishlar ro‘yxati
- [ ] Kengash/kafedra yig‘ilishi bayonnomasi
